# LAYOUT-FURNITURE-DETAILS-V1

Status: Shipped on main

## Goal

Give selected stage labels, group boxes, and guide rails the same readable-at-a-glance treatment that selected wires now have.

## Required V1 Shape

1. Show a compact details card for the currently selected layout-furniture item
2. Surface type, title, and one or two useful readouts
3. Keep the slice UI-only and adjacent to the existing structure/layout tools
4. Preserve existing drag, rename, resize, and delete behavior unchanged

## Explicit Non-Goals

- No new layout semantics
- No inspector rewrite
- No new persistence fields
- No new structure actions

## Shipped Note

MCW now shows a compact details card for the selected stage label, group box, or guide rail in the workbench actions area so layout furniture is as readable and self-describing as wires.
